## ✨ Features

- Reloads resource packs when changes to the resourcepacks folder are made (from the original [mod](https://modrinth.com/project/8xOCApGi)). 
- Prevents reloadResources() twice on Linux and macOS
- Ported to Forge and NeoForge
- Support Resourcify

# ⬇️ Installation

1. Download the mod from [Modrinth](https://modrinth.com/project/KsOce7sT) or [CurseForge](https://www.curseforge.com/minecraft/mc-mods/hot-reload-resource-packs-forked)
2. Place it into your `mods` directory
